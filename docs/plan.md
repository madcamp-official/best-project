# 게임 기획서

## 1. 개요

- **장르**: 블록체인 기반 실시간 파티 게임 (가격 예측 경매)
- **인원**: 5~10명 / 방(room) 단위
- **플레이 환경**: 모바일 앱(Flutter, iOS/Android) 및 모바일 웹
- **한 줄 요약**: 출제자가 찍은 물건 사진을 보고 나머지 참가자가 가격을 예측하며, **예측값 중 2등**이 승리하는 세컨드 프라이스(비크리 경매) 방식 파티 게임

## 2. 핵심 컨셉

이 게임은 물건의 **실제 시세를 맞히는 게임이 아니다.** 참가자들이 제출한 예측값들끼리 비교했을 때 **두 번째로 높은 값**을 낸 사람이 승리한다.

- 1등이 되어도 승리하지 못하고, 너무 보수적으로 낮게 불러도 순위권에서 밀린다.
- "다른 사람들이 대략 얼마를 부를 것인가"를 함께 추론해야 하는 심리전이 게임의 재미 요소다.
- 실제 물건 가격 정보는 게임 결과에 관여하지 않는다. (출제자가 정답을 알리거나 정산할 필요 없음)

## 3. 플레이 흐름

### 3.1 방 생성 및 입장

1. 호스트가 방을 생성한다. 공개방/비공개방을 선택할 수 있다.
   - 공개방: 방 목록에서 참가자가 자유롭게 선택해 입장
   - 비공개방: 호스트가 공유한 방 코드를 입력해 입장
2. 최소 5명 ~ 최대 10명이 모이면 호스트가 게임을 시작할 수 있다.

### 3.2 라운드 진행

1. **출제자 지정**: 참가자 명단 순서대로 로테이션하며 한 명이 해당 라운드의 출제자가 된다.
2. **사진 촬영 및 공개**: 출제자가 주변 물건을 촬영해 업로드하면, 나머지 참가자 전원에게 사진이 공개된다.
3. **예측 제출(커밋)**: 출제자를 제외한 참가자들이 각자 예측 가격을 입력해 제출한다. 제출 값은 온체인에 암호화된 형태로 커밋되어, 전원이 제출을 마치기 전까지는 본인 값 외에 아무도 열람할 수 없다.
4. **공개(리빌) 및 정산**: 제출 마감(전원 제출 완료 또는 제한 시간 경과) 시 각 예측값이 공개되고, 값을 내림차순 정렬했을 때 두 번째로 높은 값을 제출한 참가자가 해당 라운드의 승자가 된다.
5. **보상 지급**: 라운드 승자에게 ERC20 보상 토큰이 지급된다.
6. **다음 라운드**: 출제자가 다음 순서로 로테이션되며 다음 라운드가 시작된다.

### 3.3 게임 종료

- 모든 참가자가 한 번씩 출제자를 맡으면(참가자 수만큼 라운드 진행) 게임이 종료된다.
- 라운드별 승리 횟수 및 누적 보상 토큰을 합산해 최종 순위를 산출한다.

## 4. 세부 규칙 / 예외 처리

| 상황 | 처리 방안 |
| --- | --- |
| 예측값 동점(2등이 여러 명) | 동일 라운드 공동 승자로 처리, 보상 균등 분배 |
| 참가자가 제한 시간 내 예측을 제출하지 않음 | 미제출로 처리하며 순위 산정에서 제외 |
| 참가자 수가 3명 미만으로 감소 | 해당 라운드 무효 처리 또는 게임 조기 종료 (세부 기준 추후 확정) |
| 출제자가 부적절한 사진을 올린 경우 | 신고 기능을 통한 라운드 스킵 (추후 확정) |

## 5. 보상 체계

- 라운드 승자에게 ERC20 기반 보상 토큰이 지급된다.
- 토큰의 발행량, 라운드당 지급 기준, 최종 순위 보상 등 세부 이코노미는 추후 별도로 확정한다.

## 6. 미정 사항

- [ ] 라운드 제한 시간(예: 촬영 30초, 예측 제출 30초 등) 확정
- [ ] 최종 순위 산정 기준(승리 횟수 vs 누적 보상 토큰) 확정
- [ ] 신고/부적절 콘텐츠 처리 정책
- [ ] 토큰 이코노미 상세 설계
