# 시장(市長) 시뮬레이터 — 실제 지도 기반 실시간 영토 점령 게임

> **이 문서의 용도**: 게임의 현재 사양서. 서술형 기획 의도가 아니라 "무엇이 구현되어 있는지"에 초점.
> 수치·규칙의 최종 진실은 코드다 — 밸런스 값은 `web/src/config.ts`(클라)와 `server/.../config/GameConfig.kt`(서버)가 원본이며 두 파일은 항상 동기를 유지한다(convention §5 "코드가 기준").
>
> **레퍼런스**: 실제 한국 시/군/구 지도 × state.io(영토 점령) × io류 멀티플레이(방·라운드) + AI 국가들과의 전선전.

---

## 0. 게임 개요

- **지도**: 대한민국 **시/군/구 250개**가 점령 단위(셀)다. 실제 행정 경계 위에서 플레이한다.
- **목표**: 인접 셀로 병력을 보내 영토를 넓히고, **전국 51% 점유(도미네이션)** 또는 **제한 시간(30분) 종료 시 1위**로 라운드에서 승리한다.
- **PvP + AI 국가**: 방에 모인 플레이어들이 경쟁하고, 시작 시 전국에 흩뿌려진 **AI 국가 30국**이 각자 확장하며 자연스러운 전선을 만든다.
- **계급**: 셀 하나만 가져도 **시장**, 어떤 시/도를 전부 장악하면 **도지사**, 전국 40% 점유 시 **대통령**.
- **멀티플레이**: 로비에서 방을 만들거나 입장 → 대기실(방장 시작·준비 시스템) → 라운드 → 결과. 서버(Spring Boot/STOMP)가 권위, 클라는 렌더러+입력 전송기.

## 1. 기술 스택

| 영역 | 선택 | 비고 |
|---|---|---|
| 클라 빌드 | Vite + React 19 + TypeScript | |
| 지도 | MapLibre GL JS | feature-state로 소유권 색칠, CARTO 다크 베이스맵 |
| UI 상태 | Zustand | 소량만(선택 셀, HUD). 셀 배열은 React 밖 |
| 게임 상태 | typed array (`Uint8Array` 등) | `web/src/world/worldView.ts` — 서버 상태의 사본 |
| 서버 | Spring Boot (Kotlin) + STOMP WebSocket | `server/` — 게임 로직 권위. 룸 스코프 토픽 |
| 도메인 코어 | `web/src/game/core.ts` ↔ `server/.../domain/GameCore.kt` | **1:1 미러**. 순수 함수 + 주입 시계 |
| 경계 데이터 | `web/public/kr-sgg.geojson` (시/군/구 250개) | admdongkor sgg 레벨에서 추출. 클라·서버가 같은 파일·순서로 읽어 admIndex 정렬을 구조적으로 보장 |

**핵심 제약**: 셀 상태를 React state에 넣지 않는다. MapLibre 인스턴스는 1회 생성 후 명령형 갱신(dirty Set + rAF 배치). 게임 로직은 클라에서 돌리지 않는다 — 서버(개발 시엔 브라우저 내 목 서버)가 유일한 진실.

## 2. 데이터

- **소스**: `web/public/kr-sgg.geojson` — 시/군/구 250개, 속성 `sggcd`(5자리 = [시도2][시군구3])·`sggnm`·`sidocd`·`sidonm` 포함. 로더는 `web/src/data/loadMapData.ts`.
- **admIndex**: 로드 시 부여하는 0..N-1 조밀 인덱스. feature id(`promoteId`) 겸 상태 배열 인덱스. 클라·서버가 같은 파일을 같은 순서로 읽으므로 어긋날 수 없다.
- **인접 그래프**: TopoJSON 위상(`topojson.neighbors()`)으로 추출. 기하 기반 판정은 부동소수점 슬리버 때문에 쓰지 않는다.
- **아크(공유 경계선)**: TopoJSON 아크 단위로 국경선만 그린다(같은 소유주 내부 경계는 숨김). 시/도 경계는 정적 하이라이트.
- **섬**: 인접 차수 0인 셀(울릉군·옹진군 등 도서 지역)은 일반 출정으로 도달 불가 — **공수부대**가 유일한 통로(§4.7).
- **특산물 플레이버**: `web/src/data/sggSpecialty.ts` — 시/군/구별 대표 특산물·명소를 선택 패널에 표시(밸런스 무관, 표시 전용).

## 3. 게임 상태 모델

### 3.1 셀 상태 (셀당 3바이트 + 정적 메타)
```ts
ownerId : Uint8Array   // 0 = 중립, 1~ = holderId
troops  : Uint16Array  // 현재 주둔 병력
troopCap: Uint16Array  // 병력 상한 (정적)
neighborIndex: number[][]  // 인접 그래프 (정적)
```

### 3.2 holderId 간접 계층
셀은 소유자를 `holderId`로 저장하고, 별도 테이블(`holders: Map<holderId, {name, paletteIdx}>`)이 이름·색을 든다.
- `0` = 중립 · `1~199` = 플레이어 · `200~` = **AI 국가** · `255` = 예약
- AI 국가도 그냥 holder 하나 — 셀 배열·전투·이동·렌더 로직에 특수 분기가 없다. 차이는 "행동을 AI가 결정"뿐.
- 색: 고정 팔레트(중립·플레이어 5색) + AI 국가는 황금각 회전으로 프로그램 생성(`config.ts PALETTE`).

### 3.3 Order (이동 유닛)
모든 병력 이동은 `Order {from, to, amount, holderId, departTick, arriveTick}` 하나로 표현된다. 출발 시 출발지에서 즉시 차감 → 지도 위를 이동(거리 기반 시간) → 도착 시 전투/증원 판정. 공세·공수·AI 확장 전부 같은 경로를 쓴다.

## 4. 게임 규칙

### 4.1 병력 생산
- 소유 셀은 상한까지 자동 충전(`FILL_TO_CAP_SEC`). 상한 도달 시 정지, 초과분 없음.
- 상한은 현재 전 셀 균일(`BASE_CAP`).

### 4.2 출정 — 항상 전 병력(100%)
- **우클릭**(선택 셀 → 인접 셀) 또는 **우클릭 드래그**(내 셀에서 화살표를 끌어 대상에서 놓기)로 출정.
- **출정 병력은 항상 100%** — 비율 슬라이더 없음. 출발지는 비워진다(리스크 감수형 설계).
- **드래그 쓸기**: 내 셀에서 우클릭 드래그로 여러 인접 적·중립을 쓸면 병력을 **균등 분할해 동시 출정**.
- **자동 행군**: 멀리 있는 **내** 셀을 우클릭하면 내 영토만 밟는 최단 경로로 릴레이 행군.
- 증원(내 셀로 이동)은 대상의 **상한 여유분만큼만** 보낸다(초과분 소멸 방지).

### 4.3 전투 판정 (도착 시)
```
대상 Y, 도착 병력 amount:
  아군    → Y.troops = min(Y.troops + amount, cap)     // 증원
  적/중립 → Y.troops -= amount
            0 미만이면 함락: Y.owner = 나, 남은 병력 주둔
```

### 4.4 공세 목표 (더블클릭 전면 공세)
- 적·중립 셀을 **더블클릭**하면 공세 목표(⚔️) 지정. 같은 목표 재지정·내 셀 더블클릭 = 해제.
- 매 주기(`OFFENSIVE_INTERVAL_SEC`)마다 **모든 내 셀이 목표 방향으로 자동 전진**:
  - 전방(목표에 더 가까운) 이웃 중 목표 직선 방향과 가장 정렬된 셀을 고른다.
  - **최전선**(전방이 적·중립): 병력 전부로 반복 타격 — 못 이겨도 방어를 갈아내 결국 함락.
  - **후방**(전방이 내 셀): `OFFENSIVE_RATIO`만큼 앞으로 이송 → 후방→전선 보급 파이프라인이 자동 형성.
- 목표를 점령하면 자동 해제.

### 4.5 미사일
- 전국 무작위 셀에 주기적으로 스폰(시/도 균등 추첨, 맵 총량 상한). 🚀 마커.
- 미사일이 얹힌 셀의 **소유자**가 발사 가능: `Space`로 조준 → 원 범위 클릭 → **범위 내 셀 전부 중립화**(병력 0). 미사일 1개 소모.

### 4.6 전술핵 사일로 (제주)
- **제주(한라산 기슭)에 고정 사일로 1기**. 사일로 셀을 점령한 플레이어는 소모품 없이 **일반 미사일의 `NUKE_RADIUS_MULT`배 반경** 미사일을 **`NUKE_COOLDOWN_SEC`(3분)마다** 발사할 수 있다.
- 지도에 대형 🚀 마커로 상시 표시. HUD에 재장전 카운트다운.
- 사일로 섬(제주)을 **오가는 공수는 사거리 제한을 받지 않는다** — 본토에서 상륙전으로 뺏고 뺏기는 쟁탈 거점.

### 4.7 공수부대 (병력 수송)
- `Shift`로 조준 → ① 원으로 내 셀들 선택(클릭) → ② 목적지 클릭. 선택 셀 병력을 최대 `AIRDROP_MAX_TROOPS`까지 삼각형 유닛으로 투하(초과분은 출발 셀에 남음).
- 도착 시 목적지부터 인접 BFS로 순차 flood — 적·중립은 전투로 점령, 내 셀은 상한까지 증원.
- 사거리 상한(`AIRDROP_MAX_RANGE_DEG`) + 수송 상한 + 플레이어당 쿨다운. **일반 출정이 못 가는 섬에 가는 유일한 수단.**

### 4.8 포위 귀속
- 한 플레이어가 다른 **단일 플레이어**의 영역을 자기 셀만으로 완전히 둘러싸고(바깥 탈출로 없음) `ANNEX_HOLD_SEC` 연속 유지하면 **그 영역 전체를 흡수**한다(병력 0으로 리셋).
- 포위 대기 중인 셀은 반짝임으로 예고된다. 벽이 뚫리면 타이머 리셋.

### 4.9 스폰 방어막
- 신규 참가·재시작 직후 `SPAWN_SHIELD_SEC` 동안 내 셀은 **미사일·전술핵 중립화와 포위 귀속**으로부터 보호(내 능동 행동은 자유). 출정·행군·공수 같은 유닛 공격은 방어막과 무관하게 정상 전투 — 방어막은 원거리 즉사 수단만 막는다. 보호 중엔 지도에 방어막 돔 표시.

### 4.10 AI 국가
- 라운드 시작 시 **`AI_NATION_COUNT`개 AI 국가**가 전국에 서로 떨어져 단일 셀로 스폰(최원점 샘플링).
- 각자 주기적으로 "이길 만한" 인접 중립·적을 자동 점령하며 확장 — 블롭끼리 맞닿으면 서로 못 이겨 **자연 전선**이 형성된다.
- 플레이어와 동일한 규칙(생산·Order·전투)을 쓰며, 순위표에도 표시된다.

### 4.11 궤멸과 재시작
- 내 셀이 0개가 되면 GAME OVER 오버레이 — **재시작**(새 시작 셀 배정 + 방어막) 또는 메인 화면 선택.

## 5. 라운드 · 승리 · 계급

### 라운드
- **즉시 승리(도미네이션)**: 한 명이 전국 `ROUND_WIN_RATIO`(51%) 이상 점유.
- **시간 종료**: `ROUND_DURATION_SEC`(30분) 도달 시 그 시점 1위 승리. HUD 상단에 라운드 타이머.
- 종료 시 전원 결과 화면(우승자·최종 순위) → 대기실로.

### 계급 (소유권에서 파생 — 저장하지 않고 매번 계산)
```
시장   : 셀(시/군/구) 1개 이상 소유
도지사 : 어떤 시/도(sidocd)의 모든 셀을 소유
대통령 : 전국 40%(PRESIDENT_WIN_RATIO) 이상 점유 — 달성 순간 당선 연출
```

## 6. 멀티플레이 (로비 · 방 · 서버 권위)

- **흐름**: 로비(공개 방 목록) → 방 생성/입장 → 대기실(방장만 시작 가능, 나머지는 준비 토글) → 라운드 → 결과.
- **서버 권위**: 모든 게임 로직(생산·전투·AI·타이머)은 서버 `GameLoop`(5Hz tick)가 실행. 클라 명령은 STOMP로 전송하고 서버가 검증한다(비율·반경·쿨다운은 클라 값을 신뢰하지 않음).
- **프로토콜**(`docs/api-spec.md`, `web/src/net/protocol.ts`): 입장 시 `WELCOME`(전체 스냅샷 1회) → 이후 `DELTA`(변경 셀만, 5Hz) + `LEADERBOARD`(1Hz). 룸 스코프 토픽(`/topic/room/{id}/...`).
- **재접속**: 토큰(라운드 신원)·clientId(방장 신원)로 복구. 하트비트(10s)로 끊김 감지 → 자동 재연결 + "연결 끊김" 배너.
- **목 서버**: `VITE_USE_LOCAL_MOCK=1`로 띄우면 브라우저 안에서 동일 `Connection` 계약의 목 서버가 돌아 서버 없이 솔로 플레이·개발 가능.

## 7. 렌더링 · 입력

### 렌더링
- 소유권 색칠은 `setFeatureState`(paint 전용) + dirty Set + rAF 배치. 국경선은 아크 단위(소유주가 다른 경계만), 굵기는 줌 비례.
- 함락 플래시·미사일 폭발 충격파·방어막 돔·이동 유닛(원/삼각형) 보간 등 이펙트는 rAF 루프에서 갱신.
- 셀 이름·병력 숫자는 포인트 소스 + 충돌 배치(저줌에선 자동 솎아냄).

### 입력 (데스크톱)
| 입력 | 동작 |
|---|---|
| 좌클릭 | 셀 선택 (빈 곳 = 해제) |
| 우클릭 / 우클릭 드래그 | 출정(100%) · 화살표 조준 · 여러 목표 쓸기 |
| 더블클릭 | 공세 목표 지정/해제 (⚔️) |
| `WASD`/방향키 · `Q E +/-` | 연속 이동 · 줌 (동시 입력 가능) |
| `Space` | 미사일 조준 토글 |
| `Shift` | 공수부대 토글 |
| `Esc` | 조준/수송 취소 |
- 키 입력은 `e.code`(물리 키) 사용 — 한글 IME 간섭 방지. 키보드 없이도 100% 플레이 가능.

## 8. 튜닝 상수

모든 밸런스 값은 **`web/src/config.ts`의 `CONFIG` 객체 한 곳**에 모으고, 서버 `GameConfig.kt`가 1:1로 미러한다(WELCOME으로 서버 값이 클라에 전달됨 — 서버가 원본).
주요 노브: 충전 속도 · 상한 · 라운드 승리/시간 · 공세 주기/비율 · 미사일 스폰/반경 · 전술핵 배수/쿨다운 · 공수 사거리/쿨다운 · 포위 유지 시간 · 방어막 시간 · AI 국가 수/공격성. **절대값은 플레이하며 계속 튜닝 중이므로 이 문서에 적지 않는다.**

## 9. 실행 방법

```bash
# 클라 (서버 없이 목 서버로 솔로 플레이)
cd web && VITE_USE_LOCAL_MOCK=1 npm run dev

# 풀스택 (멀티플레이)
cd server && ./gradlew bootRun     # :8080 (STOMP /ws)
cd web && npm run dev              # :5173 → localhost:8080에 자동 연결
```
