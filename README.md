# best-project (가제)

몰입캠프 26s-w4-c3-04 프로젝트 repository

> 프로젝트명 미정 — 기획 단계에서 사용 중인 임시 명칭입니다.

## 소개

**블록체인 기반 실시간 가격 경매 게임**입니다.

5~10명이 하나의 방에 모여 게임을 시작하면, 매 라운드마다 한 명이 순서대로(로테이션) 출제자로 지정됩니다. 출제자는 주변의 물건을 사진으로 찍어 공유하고, 나머지 참가자들은 그 물건의 가격을 예측해 제출합니다.

이 게임의 핵심 규칙은 **2등 예측자가 승리**한다는 점입니다. 실제 물건의 시세와는 무관하며, 참가자들이 제출한 예측값들끼리 비교해 순위를 매겼을 때 두 번째로 높은 값을 제출한 사람이 그 라운드의 승자가 됩니다. (세컨드 프라이스/비크리 경매 방식)

- 너무 낮게 부르면 순위권에서 밀리고, 너무 높게 불러 1등이 되어도 승리하지 못합니다.
- 다른 참가자들의 심리와 물건의 가치를 동시에 읽어야 하는 것이 이 게임의 재미 포인트입니다.

## 게임 진행 방식

1. **방 생성/입장**: 공개 방 목록에서 참여하거나, 비공개 방은 방 코드를 입력해 입장합니다.
2. **출제자 지정**: 참가자 순서대로 로테이션하며 한 명씩 출제자가 됩니다.
3. **사진 촬영**: 출제자가 주변 물건을 촬영해 모두에게 공개합니다.
4. **가격 예측 제출**: 출제자를 제외한 나머지 참가자들이 각자 예측 가격을 제출합니다. 제출된 값은 전원이 제출을 마치기 전까지 아무도 확인할 수 없습니다.
5. **공개 및 정산**: 모든 예측이 제출되면 값이 공개되고, 2등 예측자가 해당 라운드의 승자로 결정됩니다.
6. **라운드 반복**: 출제자가 로테이션되며 여러 라운드가 진행되고, 라운드별 승리가 누적되어 최종 순위가 결정됩니다.

## 왜 블록체인인가

예측 가격은 전원이 제출을 마치기 전까지 아무도(운영 서버를 포함해) 열람할 수 없어야 공정한 게임이 됩니다. 이를 위해 예측값을 온체인에 **암호화된 형태로 커밋**하고, 라운드가 종료된 뒤에만 값을 공개(reveal)하는 **커밋-리빌(Commit-Reveal) 방식**을 채택할 예정입니다.

- 제출된 예측값은 공개 전까지 열람/수정이 불가능해 사후 조작이나 눈치 제출을 방지합니다.
- 공개된 결과와 정산 과정이 온체인에 기록되어 누구나 검증할 수 있습니다.
- 구체적인 암호화/커밋 방식(해시 커밋, 대칭키 등)과 배포할 체인/네트워크는 아직 확정되지 않았습니다.
